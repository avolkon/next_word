## 2. Архитектор: чистота кода

Найдено и устранено:

1. **Монолит в ноутбуке** — пайплайн вынесен в `scripts/`; ячейка 0.2 только bootstrap + импорты.  
2. **`train(cfg, loaders…)`** — не соответствовало «воспроизведение через train + конфиг». Теперь `result = train(cfg)`.  
3. **Test внутри fit** — утечка смысла этапа 4. Test считается только на этапе 4.  
4. **Val без стратификации** — val по квантилям калорий.  
5. **Нули в целевой** — 1 train + 1 test с 0 ккал; train/val без `calories <= 0`.  
6. **Нет конфиг-файла** — `config_full.py`.  
7. **Утечка `Image.open`** — контекстный менеджер.  
8. **`torch` импортировался внутри `collate`** — перенесён в шапку `dataset.py`.  
9. **Дубли импортов** в ячейках 2.1/2.2 — оставлены как явная проверка модулей этапа 2.  
10. **Ячейка 0.2 на 300 строк** — логика в `scripts/bootstrap.py`.

Остаётся вне кода: тяжёлые веса картинок не в git (правильно); полный MAE только с GPU.

## 3. Белый хакер: ИБ

| ID | Было | Риск | Что сделано |
|----|------|------|-------------|
| S1 | `extractall` без проверки путей | Zip Slip | члены zip только внутри `dest`; абсолютные пути и `..` режутся |
| S2 | symlink в zip | запись вне dest | symlink-записи отвергаются |
| S3 | zip bomb | диск | лимит 5 ГБ uncompressed |
| S4 | `torch.load(..., weights_only=False)` | pickle RCE | только `weights_only=True`; cfg в `best.json`; без JSON — отказ |
| S5 | `href` Яндекса без проверки хоста | SSRF / вредоносный zip | публичный URL только disk.yandex / yadi.sk HTTPS; `href` HTTPS + allowlist; редиректы с чужого хоста — отказ; TLS default context |
| S6 | `urlretrieve` + глобальный opener | порча urllib на процесс | качаем через `opener.open` чанками во временный `.part` |
| S7 | `rmtree(dest)` без рамки | снос чужой папки | распаковка только в заранее разрешённые `…/data` |
| S8 | чекпоинт с любого пути | подмена `.pt` | только файл внутри `artifacts/` |

Секретов и ключей в репозитории нет. Colab Upload по-прежнему доверяет файлу пользователя — это ожидаемо.
