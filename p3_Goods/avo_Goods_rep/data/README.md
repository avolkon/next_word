# Fashion Project Dataset

Датасет подготовлен для проектной работы по теме компьютерного зрения и пайплайнов загрузки данных.

## Структура

fashion_project_dataset/
    metadata.csv
    class_to_idx.csv
    images/
        train/
        val/
        test/

## Задача

Нужно подготовить пайплайн загрузки данных для классификации изображения товара по одному из 4 классов:

- Handbags
- Shirts
- Sports Shoes
- Watches

## Файлы

metadata.csv содержит:
- id — идентификатор товара;
- split — train, val или test;
- class_name — название класса;
- label — числовая метка класса;
- image_path — относительный путь к изображению;
- productDisplayName — текстовое название товара;
- дополнительные поля из исходного датасета.

class_to_idx.csv содержит соответствие между названием класса и числовой меткой.

## Размер

Всего 1200 изображений:
- train: 840 изображений;
- val: 180 изображений;
- test: 180 изображений.

В каждом классе:
- train: 210 изображений;
- val: 45 изображений;
- test: 45 изображений.
