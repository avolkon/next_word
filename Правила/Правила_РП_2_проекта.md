**Роль:** агент-РП (руководитель учебного проекта).  
**Архитектор:** пользователь.  
**Стоп текущего контура:** формирование **двух служебных ноутбуков** для прогона на GPU в Colab (не финальная сдача ревьюеру).

Опора: `Правила/Агент_РП_инструкции.md`, `Правила/Процесс_реализации_учебного_проекта_Autotext.md`, опыт `p1_Autotext`.

## Бриф Архитектора (исходная инструкция)

Ты РП и сейчас будешь работать над 2 новыми проектами:

1. `p2_Nutrition`
2. `p3_Goods`

### Задача

Реализовать проекты в соответствии с Правилами и опытом предыдущего проекта **до этапа формирования 2 служебных ноутбуков** для прогона на GPU в Colab.

Использовать Colab-обвязку, чтобы получить все необходимые данные для выводов и формирования финальных ноутбуков для сдачи проектов.

### До формирования служебных ноутбуков

- Выполнять предварительное тренировочное обучение на **маленьких датасетах**, так чтобы справился **CPU**.
- Не останавливать предварительное обучение, пока не проверены **до 6 конфигураций** различных настроек гиперпараметров.
- Анализировать полученные результаты и искать возможность их улучшить.
- Делать эксперименты, пока не будет достигнута наилучшая конфигурация из возможных; после этого переходить к формированию служебного ноутбука с полным датасетом для прогона на GPU.

### Дисциплина

- Не смешивать проекты.
- Сначала выполнить **1 проект** до формирования служебного ноутбука, потом приступать ко второму.
- Следить за переключением и оптимальным подбором моделей.
- При планировании и выполнении архитектурных этапов использовать более дорогие модели.
- При выполнении рутинных повторяющихся операций переключаться на бесплатную встроенную модель.

## Проекты (кратко)

### p2_Nutrition

- Задача: регрессия калорий (фото + ингредиенты), цель MAE &lt; 50.
- Код: `scripts/dataset.py`, `scripts/utils.py`, CPU-ноутбук экспериментов, `Nutrition_full_Colab.ipynb`.
- CPU: срез ~200/50/50, 6 конфигов, выбор best.
- Colab: полный датасет, GPU, чекпоинт, топ-5 ошибок.

### p3_Goods

- Задача: пайплайн подготовки данных (аудит → transforms → текст → Dataset → DataLoader), **без** обязательного обучения классификатора.
- «Эксперименты»: 6 конфигураций пайплайна (размер, max_len, aug, batch, normalize).
- Colab: скачать zip датасета, Run all этапов 1–6 с best-параметрами.
